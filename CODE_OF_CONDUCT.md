# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, specific, and evidence-driven. Harassment, discrimination, personal attacks, doxxing, and publication of private or production data are not acceptable.

Report conduct concerns privately through the maintainer's GitHub profile or the repository's private moderation/security channel. Maintainers may edit, hide, lock, or remove contributions and may temporarily or permanently restrict participation when behavior threatens a safe and productive project environment.
